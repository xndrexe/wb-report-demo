# Описание для портфолио

Название: Отчёт по магазину на Wildberries и Ozon в Excel и Google Таблицу

Скрипт сам забирает данные из кабинета продавца WB через официальный API и собирает отчёт из трёх листов: продажи и заказы по дням с отменами, возвратами, суммой к перечислению и долей рекламы, остатки по складам с прогнозом, на сколько дней хватит товара, и расходы по рекламным кампаниям. Товар, которого осталось меньше чем на две недели, подсвечен красным. Отчёт обновляется по расписанию в Excel и Google Таблице.

Для Ozon — тот же отчёт через Seller API: продажи и заказы по дням с разбивкой FBO и FBS, отменами, возвратами и начислениями Ozon; остатки по кластерам складов Ozon и на своём складе с прогнозом; заказы и возвраты по каждому товару с долей возвратов и частой причиной. Реклама Ozon — через Performance API: расход по кампаниям и по дням, показы, клики, заказы с рекламы и ДРР. Площадка выбирается одной настройкой.

Лимиты WB учтены: скрипт не упирается в «слишком часто», дожидается отчёта об остатках, сам дочитывает длинные ответы и режет длинный период по рекламе. Токен нужен только на чтение — в кабинете ничего не меняется.

Проверено: WB — на выдуманном магазине через сервер, который отвечает как API WB; Ozon, в том числе реклама, — проверено на тестах без подключения к кабинету; Google Таблица — на тестах без подключения. На живых кабинетах демо не запускалось.

Стек: Python, requests, openpyxl, gspread.
